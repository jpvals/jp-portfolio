# JP Valencia Portfolio

Personal portfolio of Juliana Patriz (JP) Valencia.

## Files
- `index.html`: the whole site (styles and scripts included)
- `images/`: profile photo and SK Brgy. IVC website screenshots
- `favicon.svg`: browser tab icon

## Deploy on Cloudflare Pages
1. In Cloudflare, go to Workers & Pages, then Create, then Pages, then Connect to Git.
2. Pick this repository.
3. Leave the framework preset as None, the build command empty, and the output directory as `/`.
4. Click Save and Deploy.

Every push to the main branch updates the live site.
